# Инструкция администратора BIMv2 (установка и настройка)

## 1. Установка приложения

1. Запустите установщик BIMv2.
2. Выполните стандартные шаги мастера:
   - выберите папку установки;
   - выберите, нужно ли создавать ярлык на рабочем столе.
3. Дождитесь сообщения об успешной установке.

## 2. Обязательная пост-настройка: запуск EXE от администратора

Это обязательный шаг. Если его пропустить, функция сброса очереди печати работать не будет.

Сделайте так:

1. Откройте папку, куда установлен BIMv2.
2. Найдите основной `.exe` файл приложения.
3. Откройте `Свойства` -> `Совместимость`.
4. Включите `Запускать эту программу от имени администратора`.
5. Нажмите `Применить` и `ОК`.

Рекомендуется также:
- запускать ярлык (если создан) с правами администратора;
- проверить UAC-политики, чтобы пользователь мог подтверждать запуск.

## 3. Где находятся настройки

Все рабочие настройки принтера, камеры и приложения находятся в файле:
- `appSettings.json` в папке установленного приложения.

Пример: `C:\Program Files\...\BIMv2\appSettings.json` (фактический путь зависит от шага установки).

## 4. Назначение полей appSettings.json

Ниже описаны поля конфигурации, кроме `LicenseSettings.SecretKey` и настроек логирования (`Logging`, `Serilog`).

### 4.1 DatabaseSettings

| Поле | Назначение |
|---|---|
| `DatabaseSettings.DbProvider` | Тип провайдера БД. Для текущей конфигурации используется `mssql`. |
| `DatabaseSettings.ConnectionString` | Строка подключения к SQL Server, где хранится служебная БД приложения. |

### 4.2 AppConfigSettings

| Поле | Назначение |
|---|---|
| `AppConfigSettings.PC_Name` | Логическое имя рабочего места/станции. Используется в общих сервисах конфигурации рабочего места. |
| `AppConfigSettings.UserDbFile` | Полный путь к файлу базы пользователей (`.xlsx`) для авторизации/работы с пользователями. |

### 4.3 FolderSettings

| Поле | Назначение |
|---|---|
| `FolderSettings.Path` | Корневая рабочая папка для обработки файлов кодов (папка «Работа с кодами»). |
| `FolderSettings.Good` | Имя подпапки «хороших»/валидированных файлов внутри `FolderSettings.Path`. |
| `FolderSettings.Archive` | Имя подпапки архива внутри `FolderSettings.Path`. |
| `FolderSettings.StatisticsOutput` | Имя подпапки, куда сохраняется статистика печати внутри `FolderSettings.Path`. |
| `FolderSettings.CameraStatisticsOutput` | Имя подпапки, куда сохраняются TXT-файлы с кодами камеры по завершенным заданиям (создается автоматически внутри `FolderSettings.Path`). |
| `FolderSettings.Duplicates` | Имя подпапки для файлов с дубликатами внутри `FolderSettings.Path`. |

### 4.4 LabelStarSettings

| Поле | Назначение |
|---|---|
| `LabelStarSettings.FileName` | Имя генерируемого рабочего файла для печати (обычно `NewTest.txt`) в рабочей папке. |

### 4.5 PrinterSettings

| Поле | Назначение |
|---|---|
| `PrinterSettings.IP` | IP-адрес принтера для мониторинга статуса и управляющих команд (пауза/продолжить/сброс). |
| `PrinterSettings.Port` | TCP-порт принтера (обычно `9100` для RAW-команд). |

### 4.6 CameraSettings

| Поле | Назначение |
|---|---|
| `CameraSettings.IP` | IP-адрес камеры сканирования кодов. |
| `CameraSettings.Port` | TCP-порт камеры (в текущей конфигурации используется `23`). |
| `CameraSettings.ModuleAvailable` | Флаг включения/отключения модуля камеры в интерфейсе и рабочих процессах (`true`/`false`). |

### 4.7 Прочие поля

| Поле | Назначение |
|---|---|
| `UseInMemoryDatabase` | Служебный флаг для in-memory режима (в текущем рабочем сценарии обычно `false`). |

### 4.8 AppMode

| Поле | Назначение |
|---|---|
| `AppMode.OfflinePrinterFlow` | Дополнительный офлайн-режим. При `true` отключаются модуль камеры, сетевое подключение/мониторинг принтера и проверки подключения устройств; кнопки паузы/снятия с паузы скрываются, файл по завершении переносится в архив, статистика формируется в упрощенном виде. При `false` приложение работает в обычных режимах (камера+принтер или только принтер). |

## 5. Минимальный чек-лист после установки

1. BIMv2 запускается.
2. EXE запускается от имени администратора.
3. `appSettings.json` заполнен корректно:
   - доступен SQL Server (`ConnectionString`);
   - корректные `PrinterSettings` (если `AppMode.OfflinePrinterFlow=false`);
   - корректные `CameraSettings` (если модуль камеры используется);
   - корректно выбран `AppMode.OfflinePrinterFlow` под сценарий линии;
   - существует путь `FolderSettings.Path` и доступны права записи.
4. Приложение видит принтер и (при включенном модуле) камеру.
5. Команды паузы/продолжения выполняются штатно.
6. Сброс очереди печати выполняется без ошибок доступа.

## 6. Типовые ошибки при вводе в эксплуатацию

1. Не включен запуск от администратора -> сброс очереди печати не работает.
2. Неверный IP/порт принтера -> нет статуса принтера и не проходят команды управления.
3. Неверный IP/порт камеры -> нет входящих кодов и/или блокировки по соединению.
4. Неверный путь `FolderSettings.Path` или нет прав -> проблемы с перемещением файлов и статистикой.
5. Неверный путь `AppConfigSettings.UserDbFile` -> проблемы с загрузкой пользовательской базы.
6. Неверно установлен `AppMode.OfflinePrinterFlow` -> ожидания по поведению не совпадают (например, нет паузы/мониторинга принтера в офлайн-режиме).
